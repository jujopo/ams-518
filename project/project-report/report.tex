	\section{Problem and Model Formulation}
	The main objective of this project is to analyze the performance of a specific equity portfolio from the perspectives of three different hypothetical personas. This analysis will be extended to include a formal evaluation of risk-adjusted returns and the construction of an index-tracking portfolio. 
	
	\subsection{Core problem definition}
	% Define the 10-stock portfolio here.
	The core analysis is centered on a portfolio composed of 10 U.S. stocks, which were selected to represent a mix of technology, dividend aristocrat\footnote{A dividend aristocrat is an S\&P 500 company that has increased its dividend annually for at least 25 years, demonstrating a commitment to returning cash to investors}, and high-dividend yield sectors. The portfolio is defined by
	\begin{itemize}
		\item \textbf{Technology:} MSFT, AAPL, IBM
		\item \textbf{Dividend aristocrat:} XOM, WTM, KO, JNJ
		\item \textbf{High dividend yield:} VZ, KHC, USB
	\end{itemize}
	The performance of this 10-stock target portfolio will be evaluated using historical market data, we assume a specific weighting strategy defined in Section 2. 
	
	\subsection{Persona models (Stochastic Models)}
	The performance of the target portfolio is evaluated through three personas, each representing a different investment horizon and objective. The PnL for each is modeled as a stochastic process dependent on the historical price path of the portfolio's assets.
	
	\subsubsection{Buy \& Hold (BH) model}
	This persona represents a long-term investor who acquires the portfolio at the beginning of the analysis period and holds it until the end.
	\begin{itemize}
		\item \textbf{Objective:} Maximize total return over the entire period, inclusive of all cash dividends. 
		\item \textbf{Model:} The PnL is a single-stage calculation: $\text{PnL}_\text{BH} = \text{Value}_{E} - \text{Value}_{S}$
	\end{itemize}
	
	\subsubsection{Hedge Fund (HF) model}
	This persona represents an institutional investor that marks-to-market\footnote{Accounting method that values assets and liabilities at their current market price rather than their historical or original cost} and captures PnL changes on a daily basis.
	\begin{itemize}
		\item \textbf{Objective:} Generate consistent, positive daily returns (alpha) while managing daily volatility.
		\item \textbf{Model:} The PnL is a multi-stage stochastic series: $\text{PnL}_{HF}(t) = \text{Value}_t - \text{Value}_{t-1}$ for each day $t$.
	\end{itemize}
	
	\subsubsection{Day Trader (DT) model}
	This persona represents a short-term speculator who seeks to profit from intraday price movements and holds no overnight positions.
	\begin{itemize}
		\item \textbf{Objective:} Achieve positive PnL from a defined intraday trading strategy.
		\item \textbf{Model:} The PnL is a strategy-dependent daily series, $\text{PnL}_{DT}(t) = PnL_{\text{Strategy}, t}$.
	\end{itemize}
	
	\subsection{Risk Constraints and Performance Metrics}
	A simple return analysis is insufficient. We introduce risk constraints by evaluating each persona's PnL stream using standard performance metrics.
	
	\begin{itemize}
		\item \textbf{Sharpe Ratio:} Measures risk-adjusted return, defined as:
		\begin{equation}
			\text{Sharpe Ratio} = \frac{E[R_p - R_f]}{\sigma_p}
		\end{equation}
		where $R_p$ is the portfolio's return, $R_f$ is the risk-free rate, and $\sigma_p$ is the standard deviation (volatility) of the portfolio's excess return.
		
		\item \textbf{Value at Risk (VaR):} Defines the maximum expected loss at a given confidence level $1-\alpha$. It is the $1-\alpha$ quantile of the PnL distribution, $F_X(x)$.
		\begin{equation}
			\text{VaR}_{\alpha}(X) = - \inf \{x \in \mathbb{R} : F_X(x) > \alpha\}
		\end{equation}
		For this project, we will use the non-parametric Historical Simulation method.
		
		\item \textbf{Conditional Value at Risk (CVaR):} Measures the expected loss \textit{given} that the loss exceeds the VaR.
		\begin{equation}
			\text{CVaR}_{\alpha}(X) = E[-X \mid -X \ge \text{VaR}_{\alpha}(X)]
		\end{equation}
	\end{itemize}
	
	\subsection{Index Tracking Model (Optimization Model)}
	This task involves creating a replicating portfolio from a universe of other stocks (e.g., S\&P 500 components excluding the 10 target stocks) to mimic the returns of our target portfolio. This is formulated as a constrained optimization problem.
	
	\begin{itemize}
		\item \textbf{Objective Function:} Minimize the Tracking Error Variance (TEV), which is the variance of the difference between the target portfolio's returns ($R_T$) and the replicating portfolio's returns ($R_R$).
		\begin{equation}
			\min_{w} \quad \text{TEV} = E\left[ \left( R_T(t) - R_R(t) \right)^2 \right]
		\end{equation}
		where $R_R(t) = \sum_{i=1}^{N} w_i R_i(t)$ and $w_i$ is the weight of stock $i$ in the replicating portfolio.
		
		\item \textbf{Constraints:} The optimization is subject to several constraints:
		\begin{enumerate}
			\item \textbf{Full Investment:} Weights must sum to one.
			\begin{equation}
				\sum_{i=1}^{N} w_i = 1
			\end{equation}
			\item \textbf{Long-Only:} No short selling is permitted.
			\begin{equation}
				w_i \ge 0 \quad \forall i \in \{1, \dots, N\}
			\end{equation}
			\item \textbf{Cardinality Constraint:} The number of stocks in the replicating portfolio must not exceed $k$ (e.g., $k=20$). This is represented using the $L_0$-norm:
			\begin{equation}
				\|w\|_0 \le k
			\end{equation}
			\item \textbf{Buy-In Constraint:} Any selected stock must have a minimum weight of $l$ (e.g., $l=1\%$). This makes the weights semi-continuous:
			\begin{equation}
				w_i \in \{0\} \cup [l, 1] \quad \forall i
			\end{equation}
		\end{enumerate}
	\end{itemize}
